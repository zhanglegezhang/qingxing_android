# 轻醒 1.1.3 验证记录

验证日期为 2026-11-13。版本号、APK 签名和文件哈希见 `release/latest.json`。

- 按返回键退出或从最近任务移除轻醒时停止虚拟定位，移除模拟来源。按 Home、切换应用和锁屏时继续模拟。重新打开应用时，需再次手动启动模拟。
- 1.1.3 启用新的正式签名。独立 Android 16 模拟器确认旧签名的 1.1.2 无法直接覆盖升级，卸载后可全新安装。导入设置可恢复公司 Wi-Fi、提醒时段及工作日设置。导出设置文件不包含打卡记录，重装后需要重新授权。
- 九个适用测试组通过，包括重装与导入的 19 项检查、模拟定位组 50 项检查、地图组 17 项检查、当前位置组 15 项检查及完整冒烟 109 项检查。旧签名历史包的两组覆盖升级不适用，发布记录保留了原因。
- 独立测试 AVD 为 `QingxingSmoke16`。在 `QingxingAndroid16` 预览 AVD 验证启动及首次授权界面，并从设备拉回已安装 APK 核对版本、证书指纹及 SHA256。真机表现仍需在目标设备验证。
